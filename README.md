# SubtitleSync

**简体中文** | [English](README.en.md)

SubtitleSync 是一款简单的 **字幕悬浮显示工具**。

你可以加载本地字幕文件，并让字幕跟随时间播放。如果你在 Chrome 或 Edge 中观看视频，还可以通过浏览器扩展，让字幕自动跟随视频的播放、暂停和快进。

支持 `.srt`、`.ass`、`.ssa` 字幕。

## 主要功能

- 支持 SRT、ASS、SSA 字幕
- 点击任意字幕，可从该位置开始播放
- 支持播放、暂停、上一句、下一句
- 支持前后微调字幕时间
- 独立字幕悬浮窗，可自由调整大小
- 字幕窗口始终置顶，方便搭配网页视频使用
- 可调整字幕字号和背景透明度
- 支持 Chrome / Edge 视频同步
- 自动保存窗口位置和字幕设置
- 支持最小化到系统托盘
- 移除字幕不会删除原字幕文件

## 基本使用

1. 打开 SubtitleSync。
2. 点击 **“上传字幕文件”**。
3. 选择一个 `.srt`、`.ass` 或 `.ssa` 字幕文件。
4. 点击字幕列表中的一句字幕，确定开始位置。
5. 点击播放，字幕就会按照时间轴自动显示。

播放过程中可以使用 **上一句、下一句、暂停** 等按钮调整字幕。

## 浏览器视频同步

如果你希望字幕跟随网页中的视频一起播放，可以安装项目自带的 Chrome / Edge 扩展。

1. 打开 `chrome://extensions` 或 `edge://extensions`
2. 开启 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择项目中的 `browser-extension` 文件夹
5. 启动 SubtitleSync 并加载字幕
6. 播放网页视频

之后视频的 **播放、暂停、快进和后退** 都会自动同步到字幕。

## 设置

点击主窗口顶部的 **设置**，可以调整：

- 字幕字号
- 悬浮窗背景透明度
- 关闭窗口时是否最小化到系统托盘

这些设置会自动保存，下次打开软件时继续使用。

如果开启了 **关闭时最小化到托盘**，关闭主窗口不会真正退出程序。

需要完全退出时，可以在系统托盘中选择 **“退出程序”**。

## 开发运行

安装依赖：

```bash
npm install
```

启动程序：

```bash
npm start
```

也可以直接运行：

```bash
start.bat
```

## Windows 打包

生成 Windows 安装包：

```bash
npm run dist
```

打包后的文件位于：

```text
release/
```

安装后会自动创建桌面和开始菜单快捷方式。
